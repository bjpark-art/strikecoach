# StrikeCoach (M0 웹앱)

PRD의 M0 범위: 카메라 자세 인식 + 펀치/킥 카운트 + 가드 하락 감지 + 음성 큐 + 세션 리포트.
빌드 도구 없이 ES 모듈로 동작하고, 자세 인식은 MediaPipe Pose Landmarker를 브라우저에서 돌린다(CDN에서 로드, 인터넷 필요).

## 실행

```bash
python -m http.server 5173 --bind 127.0.0.1 --directory app
```

- 앱: http://localhost:5173
- 테스트: http://localhost:5173/tests.html (제목이 PASS면 통과)
- 웹캠이 없거나 권한이 없으면 촬영 준비 화면에서 "데모로 해보기"로 합성 자세 데이터를 써서 전체 흐름을 돌릴 수 있다.
- 휴대폰에서 카메라를 쓰려면 https 주소가 필요하다(브라우저 정책). PC에서는 localhost라 바로 된다.

## 구조

| 경로 | 역할 |
|---|---|
| `js/analysis/analyzer.js` | 프레임 단위 분석: 잽/크로스, 킥, 가드 하락, 가드 유지율 |
| `js/feedback/cues.js` | 음성 큐 규칙(한 번에 하나, 같은 큐 10초 간격) + 음성 출력 |
| `js/pose/camera-source.js` | 전면 카메라 + MediaPipe |
| `js/pose/demo-source.js` | 카메라 없이 쓰는 합성 자세(테스트 기대값의 기준) |
| `js/screens/*` | 온보딩, 홈, 촬영 준비, 실시간 훈련, 리포트 |
| `js/store.js` | 설정·세션 기록(localStorage, 영상은 저장 안 함) |
| `css/app.css` | 디자인 토큰(ux-prototype.html과 같음) |

## 영상 분석 (1인)

- 홈 > 영상 분석에서 훈련 영상을 고르면 20fps로 프레임을 넘기며 분석한다(`js/pose/video-analyzer.js`).
- 영상은 저장하지 않고, 관절 좌표만 IndexedDB에 저장한다(`js/pose/frames.js`, `js/db.js`). 리뷰 때 같은 파일을 다시 고르면 뼈대를 겹쳐 보여준다.
- 영상 리뷰: 가드 하락 마커, 인식 끊김 구간, 0.25x 슬로모션, 뼈대 켜기/끄기.
- 리뷰 화면의 "판정 정확도 높이기"에서 실제 횟수와 함께 관절 좌표 JSON을 저장할 수 있다. 판정 기준 보정용.

## 상체 모드

엉덩이가 화면에 안 보이면 몸통 길이 대신 3D 어깨 너비 × 1.4를 기준 길이로 써서 펀치·가드를 계속 판정한다(킥은 다리가 보일 때만). 촬영 준비 화면은 "상체만 보여요"로 안내한다.

## 스파링 분석 (2인)

1. 영상에서 프레임마다 최대 2명 자세 추정 (`js/pose/video-analyzer.js`, `people: 2`)
2. 위치·크기로 두 사람을 이어 붙임, 겹친 구간 표시 (`js/sparring/tracker.js`)
3. 사람별 동작 분석 + 스탠스 자동 추정(상대에 가까운 손 = 앞손)
4. 유효타 후보(뻗은 순간 주먹·발이 상대 머리/몸통 근처), 압박(1초 단위 전진) (`js/sparring/interaction.js`)
5. 라운드별 채점 → AI 추정 우세, 신뢰도 낮으면 판정 보류 (`js/sparring/judge.js`, 가중치는 `WEIGHTS`)

실제 타격 성공, 방어(블록·슬립), 클린치, 니·엘보는 판정하지 않는다. 결과는 공식 판정이 아니다.

## 훅·어퍼컷 (펀치 종류 분류기)

- `js/analysis/punch-classifier.js`: 손목이 빠르게 움직인 2D 구간을 잡아 스트레이트/훅/어퍼컷/펀치 아님으로 분류. 훅·어퍼컷만 세고(스트레이트는 3D 규칙), 확률 0.55 미만, 같은 팔 스트레이트와 겹침, 가드 하락에서 손을 올리는 동작은 세지 않는다.
- `js/analysis/punch-model.js`: 자동 생성된 그래디언트 부스팅 트리. BoxingVI 영상 6개(V4·V5·V7·V8·V9·V10)를 앱과 같은 MediaPipe로 분석한 좌표로 학습했고, 감지 구간 단위로 영상 하나 빼고 검증 58.6%. 감지 기준값(`detect`)도 함께 들어 있다. 생성 스크립트는 저장소 밖 `tools/validate/train_mp.py`.
- 실제 영상 기준 앱 전체 정확도(같은 6개 영상, 영상 하나 빼고 학습한 모델로 채점): 정답 펀치의 약 29%를 세고, 감지한 것의 약 16%가 없는 펀치. 기준값은 `createAnalyzer({ tune })`로 바꿔 시험할 수 있다(`DEFAULT_TUNE`).
- BoxingVI 데이터는 라이선스가 명시돼 있지 않다. 출시 전 저자 허락이 필요하다.
- 판정 보정 데이터 내보내기는 개발자용: `localStorage.setItem('strikecoach.dev', '1')`
